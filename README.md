# User Management API

A lightweight and efficient RESTful Web API built with ASP.NET Core Minimal APIs using C#. This project demonstrates core backend development concepts including custom middleware, thread-safe in-memory data management, and automated API documentation.

## Features

- **Minimal APIs Architecture:** Streamlined, fast, and modern routing setup.
- **CRUD Operations:** Complete functionality to Create, Read, Update, and Delete user records.
- **Thread-Safe Data Storage:** Utilizes `ConcurrentDictionary` for reliable, lock-free in-memory data management.
- **Custom Logging Middleware:** A custom-built middleware pipeline that intercepts and logs incoming HTTP requests (Method, Path) and outgoing response status codes.
- **Interactive API Documentation:** Fully integrated with Swagger/OpenAPI for easy testing and endpoint exploration.

## Technologies Used

- C#
- .NET (ASP.NET Core)
- Swagger / Swashbuckle for OpenAPI documentation
